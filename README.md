# Operation-control-system

## 🧭 프로젝트 구조
- `ViewModels/` : MVVM 로직
- `Services/` : 통신 및 백엔드 로직
- `Models/` : 데이터 구조
- `Resources/` : UI 리소스
- `App.xaml` : 진입점
- `MainWindow.xaml` : 메인 GUI

## 🔄 브랜치 전략
- main : 안정 릴리즈
- develop : 개발 통합
- feature/* : 기능 구현 단위
